# Contributing to Music Recommendation Using Facial Expressions

Thank you for your interest in contributing! We welcome contributions from everyone.

## How to Contribute

1.  **Fork the repository** to your own GitHub account.
2.  **Clone your fork** to your local machine.
3.  **Create a new branch** for your feature or bug fix:
    ```bash
    git checkout -b my-new-feature
    ```
4.  **Make your changes**.
5.  **Test your changes** to ensure everything works as expected.
6.  **Commit your changes** with descriptive commit messages.
7.  **Push your branch** to your fork:
    ```bash
    git push origin my-new-feature
    ```
8.  **Open a Pull Request** (PR) on the main repository.

## Development Setup

1.  Navigate to the `code` directory: `cd code`
2.  Install dependencies: `pip install -r requirements.txt`

## Reporting Issues

If you find a bug or have a suggestion, please open an issue on the GitHub repository. Provide as much detail as possible.
